---

### Funil de 3 Fases

```

Objectivo: trazer trafico qualificado para a landing page do livro
KPI: CPM < 8 EUR, CTR > 1,5%
Periodo: 27/Abr — 26/Mai (30 dias antes da Feira)

        |
        v

FASE 2: CONSIDERACAO (publico morno)
Objectivo: captar leads (email) e gerar pre-vendas
KPI: CPL < 3 EUR, CPA < 8 EUR
Periodo: 12/Mai — 26/Mai (2 semanas antes da Feira)

        |

FASE 3: CONVERSAO (retargeting)
Objectivo: converter visitantes e engagers em compradores
KPI: CPA < 5 EUR, ROAS > 4:1
Periodo: 27/Mai — 14/Jun (durante a Feira) + 7 dias apos
```

## Formulas de Calculo

```
ROAS = Receita Total / Investimento em Ads
CPA = Investimento Total / Numero de Vendas
CPL = Investimento em Captacao / Numero de Leads
Breakeven CPA = Preco do Livro (16 EUR) - Custo de Producao (~5 EUR) = 11 EUR max
```

**Nota:** O CPA breakeven e 11 EUR se considerarmos apenas o livro. Mas o valor real do cliente inclui o funil:
- Livro: 16 EUR (margem ~11 EUR)
- Masterclass upsell: 197 EUR (conversao estimada: 5-10%)
- Mentoria: 1.997 EUR (conversao estimada: 1-2%)

**LTV estimado por lead:** 16 EUR + (197 x 7,5%) + (1.997 x 1,5%) = 16 + 14,78 + 29,96 = **60,74 EUR**

Isto significa que um CPL de 3 EUR e altamente rentavel quando se considera o funil completo.

# 7. PLANO DE TESTES A/B

---

## 5 Testes Prioritarios

---

### Teste 1 — Imagem Estatica vs Video 15s

| Parametro | Detalhe |
|-----------|---------|
| **Hipotese** | Video gera mais engagement e CTR que imagem estatica em publico frio |
| **Variavel** | Formato criativo (imagem 1080x1080 vs video 15s) |
| **Constantes** | Mesmo copy (versao media), mesma audiencia (FRIO-DP-PT), mesmo CTA |
| **Criativos** | Variante 4 (Dor) — versao imagem vs versao video |
| **Metrica principal** | CTR |
| **Metrica secundaria** | CPC, CPM |
| **Orcamento** | 50% para cada variante |
| **Duracao minima** | 5 dias ou 1.000 impressoes por variante |
| **Decisao** | Vencedor passa a receber 80% do orcamento |

---

### Teste 2 — Copy Curto vs Copy Longo

| Parametro | Detalhe |
|-----------|---------|
| **Hipotese** | Copy longo gera mais conversao em publico morno (ja conhece a marca) |
| **Variavel** | Extensao do primary text (curto ~30 palavras vs longo ~150 palavras) |
| **Constantes** | Mesmo criativo visual (Variante 3 — Numeros), mesma audiencia (LAL-EMAIL-1%), mesma headline |
| **Metrica principal** | CPL (custo por lead) |
| **Metrica secundaria** | CTR, tempo na landing page |
| **Orcamento** | 50% para cada variante |
| **Duracao minima** | 5 dias ou 500 cliques totais |
| **Decisao** | Vencedor passa a formato default para a fase de consideracao |

---

### Teste 3 — Angulo Citacao vs Angulo Historia

| Parametro | Detalhe |
|-----------|---------|
| **Hipotese** | Historia de origem gera mais conexao emocional e saves/shares que citacao isolada |
| **Variavel** | Angulo do copy (Variante 1 — Citacao vs Variante 2 — Historia) |
| **Constantes** | Mesma audiencia (FRIO-LIVROS-PTBR), mesmo formato (carrossel 1080x1080) |
| **Metrica principal** | Engagement rate (saves + shares) |
| **Metrica secundaria** | CTR, CPM |
| **Orcamento** | 50% para cada variante |
| **Duracao minima** | 7 dias |
| **Decisao** | Vencedor define o angulo dominante para publico frio |

---

### Teste 4 — CTA "Reserva o Teu" vs "Saber Mais"

| Parametro | Detalhe |
|-----------|---------|
| **Hipotese** | "Reserva o Teu" gera mais conversao directa; "Saber Mais" gera mais cliques e leads |
| **Variavel** | Botao CTA da Meta (Reservar vs Saber Mais) |
| **Constantes** | Mesmo copy (Variante 6 — Countdown, versao media), mesma audiencia (RTG-ENGAGE-30D), mesmo criativo |
| **Metrica principal** | CPA (para "Reservar"), CPL (para "Saber Mais") |
| **Metrica secundaria** | CTR, ROAS |
| **Orcamento** | 50% para cada variante |
| **Duracao minima** | 5 dias ou 200 cliques totais |
| **Decisao** | Usar "Reservar" em conversao e "Saber Mais" em awareness — confirmar com dados |

---

### Teste 5 — Audiencia Interesse vs Lookalike

| Parametro | Detalhe |
|-----------|---------|
| **Hipotese** | Lookalike (base de emails aquecida) supera audiencia de interesses em CPA |
| **Variavel** | Audiencia (FRIO-DP-PT vs LAL-EMAIL-1%) |
| **Constantes** | Mesmo criativo (Variante 3 — Numeros, versao media), mesmo CTA (Saber Mais), mesmo orcamento |
| **Metrica principal** | CPA |
| **Metrica secundaria** | CPL, CTR, qualidade do lead (email valido) |
| **Orcamento** | 50% para cada variante |
| **Duracao minima** | 7 dias ou 300 cliques totais |
| **Decisao** | Vencedor recebe 70% do orcamento de fase de consideracao |

---

## Protocolo de Testes

| Regra | Detalhe |
|-------|---------|
| **Nunca alterar 2 variaveis ao mesmo tempo** | Cada teste isola 1 variavel |
| **Significancia estatistica** | Minimo 95% de confianca antes de declarar vencedor |
| **Nao parar testes antes do tempo** | Minimo 5 dias OU volume minimo de dados |
| **Documentar resultados** | Registar vencedor, margem, insights para futuros lancamentos |
| **Escalar vencedores** | Alocar 70-80% do orcamento ao vencedor, manter 20-30% a testar |
